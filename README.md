## 📌 Conteúdos Principais Desenvolvidos
1. **Ferramental Oficial:** Configuração do MongoDB Database Tools (`mongodump` e `mongorestore`) e inclusão no PATH do Windows.
2. **Backups Estruturados:** Realização de backup completo da instância e backup incremental simulado via coleção específica (`orders`).
3. **Simulação de Desastre:** Teste de destruição controlada de base (`db.dropDatabase()`) e recuperação bem-sucedida com validação de dados e índices.
4. **Respostas Avaliativas:** Resolução teórica aprofundada sobre diferenças de backup, automação, RTO/RPO e verificação de integridade por checksums e testes de fumaça.
